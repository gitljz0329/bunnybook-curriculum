# Big Question Linking Guidelines

Big Question 关联用于说明一个课程锚点可能被哪个元问题框架统摄。它不是课程标准原文的一部分，通常是基于来源章节、摘要和教学解释做出的推断或作者判断。

## 何时链接 0 个 BQ

- 课程锚点只是技术性目录、页码或结构信息。
- 候选摘要过于泛泛，无法解释与某个元问题的关系。
- 关联只来自“这个学科一般会涉及某问题”的常识。
- 来源定位或短摘录需要先人工核对。

## 何时链接 1 个 BQ

- 锚点明显指向一个核心元问题，例如证据判断、系统建模、可持续、文化表达、公共生活或行动创造。
- 第二个关联只是弱关键词或学科倾向。
- 教师审阅时能用一句话解释为什么这个 BQ 是主要框架。

## 何时链接 2 个 BQ

- 锚点同时具有两个清楚的概念方向。
- 两个方向都能从标题、摘要、短摘录或来源章节解释。
- 第二个 BQ 不是为了凑数，而是能帮助教师看见另一种备课入口。

## evidence_level

BQ 关联通常使用：

- `inferred`: 基于章节结构、候选摘要和上下文合理推断。
- `author`: 基于项目设计或教学经验做出的解释性判断。
- `uncertain`: 依据较弱，需要人工复核。

除非来源文本直接明确指向某个 Big Question，否则不要使用 `direct`。

## 常见误判

- 仅凭学科就链接，例如“数学一定是 BQ3”。
- 仅凭单个关键词就链接，例如看到“数据”就自动链接 BQ5。
- 每个候选强行链接两个 BQ。
- 把核心素养标签当成大问题本身。
- 把评价建议都等同于“证据、真相与判断”，而不看具体评价内容。

## 示例

1. 生物学课程目标中涉及人与自然和生命现象理解，可优先考虑 `BQ4`；如果还明确涉及证据论证，可再考虑 `BQ2`。
2. 数学建模或函数变化内容可考虑 `BQ3`；如果只是课程结构说明，可能不需要 BQ。
3. 信息技术中涉及算法、数据和数字社会的锚点可考虑 `BQ5`；如果同时强调信息判断，可考虑 `BQ2`。
4. 艺术、语文、英语中涉及表达、文化理解和意义建构的锚点可考虑 `BQ6`。
5. 思想政治中涉及公共参与、法治、责任和制度的锚点可考虑 `BQ7`，但不能仅凭学科名称自动链接。
