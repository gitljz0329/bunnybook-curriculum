# BunnyBook 品牌与域名发布准备

更新日期：2026-07-11

## 推荐命名结构

- 主品牌：**BunnyBook**
- 正式产品名：**BunnyBook Curriculum**
- 中文描述：**给备课 Agent 的课标知识底座**
- MCP 服务名：`BunnyBook Curriculum Source`
- Kimi Code 插件 ID：`bunnybook-curriculum`
- 首屏卖点：**让你的备课 Agent 不再凭空编课**

“BunnyBook Curriculum”用于 Manifest、插件、仓库和法律文件，可以降低裸名称的混淆；主站视觉仍可只显示 BunnyBook。

## 名称风险

`BunnyBook` 不是空白名称：`bunnybook.app` 已用于另一款记录/陪伴类应用，`bunnybook.net` 也已有兔子相关服务。因此当前改名是产品方向，不等于已经完成商标清查或取得全球独占权。

正式公开前应至少做中国第 9 类、41 类、42 类及目标市场的商标近似检索。未完成检索前，不使用“唯一”“官方”或“已注册商标”等表述。

## 域名优先级

以下是 2026-07-11 的 RDAP 初筛结果，只表示当时没有查到注册对象，不等于注册商一定可售，也不代表没有溢价、保留词或商标风险。

1. `bunnybook.school`：品牌与教育场景最一致，推荐作为主域名首选。
2. `usebunnybook.com`：更稳妥的 `.com` 行动型域名，适合早期产品和社交传播。
3. `bunnybook.ai`：最短、技术感最强，但名称冲突风险更高，也可能是高价域名。
4. `bunnybookcurriculum.com`：清晰但较长，可作为防御性域名。

已知不可作为首选：

- `bunnybook.com` 已注册。
- `bunnybook.app` 已有正在使用的同名产品。
- `.cn` 状态在本次 RDAP 查询中无法可靠确认，需要通过注册商单独查询。

域名尚未购买。正式购买前应先做商标检索，再由项目权利人本人完成注册与实名信息填写。
