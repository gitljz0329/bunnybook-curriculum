# 课程锚点候选抽取指南

`curriculum_anchor_candidate` 是进入正式图谱之前的候选项。它帮助测试从课程标准来源地图到 Big Question、主题、学科角色和评价证据的工作流，但它本身不是正式图谱节点。

## 候选项如何进入正式表

1. 人工打开对应 PDF，核对 `source_ref`、页码、章节和短摘录。
2. 确认 `teacher_friendly_summary` 是否忠于来源，又足够适合教师使用。
3. 将合格候选的 `review_status` 标为 `accept`，需要修改的标为 `revise`，不合适的标为 `reject`。
4. 只有人工确认后的内容，才复制或改写进入 `data/working/curriculum_anchors.csv`。

## evidence_level 判断

- `direct`: 来源文本直接表述该内容。
- `inferred`: 基于章节结构或上下文合理推断。
- `author`: 作者或系统为了备课图谱做出的解释性判断。
- `uncertain`: 尚不确定，需要人工复核。

Big Question 关联通常不是 PDF 直接表述，所以默认使用 `inferred` 或 `author`，不要轻易标为 `direct`。

## 避免复制课标原文

- `source_snippet_short` 只用于人工核对，最多保留 120 个中文字符。
- `teacher_friendly_summary` 必须是原创摘要，不应照搬长句。
- 对外展示优先使用结构化关系、短标签、原创解释和来源定位。

## teacher_friendly_summary 写法

好的摘要应该回答：

- 这条锚点对教师备课有什么用？
- 它支持的是目标、内容、素养、学业质量、教学建议还是评价建议？
- 它如何帮助后续设计主题任务或评价证据？

摘要不需要覆盖章节全部内容，也不应替代课程标准原文。

## 何时适合链接 Big Question

适合链接的情况：

- 锚点明显涉及某个元问题的核心概念，例如证据、系统、可持续、技术、文化、公平或行动。
- 学科内容能在跨学科主题活动中承担清楚角色。
- 关联可以用标题、摘要、学科或章节位置解释。

不适合链接的情况：

- 关联只靠想象，无法从锚点信息解释。
- 只是泛泛地说“都能联系”。
- 候选项本身抽取质量低或来源定位不清。
