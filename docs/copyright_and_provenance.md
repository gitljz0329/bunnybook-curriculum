# 版权与来源说明

原始 PDF 只用于本地研究和整理。项目不会移动、删除或重命名原始文件。

公开数据不要大段复制教材、课标、真题或其他来源文本。推荐使用：

- 原创摘要。
- 短标签。
- 结构化关系。
- 文件名、页码、章节名或条目位置。

每个从 PDF 得出的条目都必须保留 `source_ref`。如果内容来自 AI 推断，还必须标注 `evidence_level`，并在必要时使用 `uncertain` 等待人工复核。

对外展示时，优先使用原创解释和结构化关系。对于版权状态不确定的内容，只保留文件名、页码、条目定位、短标签和原创解释。

13 份本地 PDF 的哈希、公开包处理状态和待核对来源页记录在 `data/catalog/source_rights.csv`。许可分层、第三方排除范围和正式激活条件见 `docs/licensing_plan.md`；在正式权利人确认前，项目不授予开放许可。
