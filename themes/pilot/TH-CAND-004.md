# 数据会不会骗人：教师共备样张

- Theme id: `TH-CAND-004`
- Status: `pilot_draft`
- Primary Big Question: `BQ2`
- Secondary Big Question: `BQ3`
- 建议时长: 4-5 课时，可压缩为一次跨学科项目周任务

## 为什么先做这张

它把 Big Question 里的“证据、真相与判断”落到所有高中学科都能使用的数据判断任务上，材料容易获得，适合作为第一张低门槛共备样张。

## 教师准备

- 准备 2-3 组围绕同一议题但结论不同的数据表达，例如新闻图表、校园调查摘要或公开报告截图。
- 提前标出可能误导学生的点：样本范围、统计口径、坐标轴、缺失变量、因果偷换。
- 为学生提供一张空白的数据可信度审查表和一张图表重绘模板。

## 材料包

- 同一议题的多来源数据或图表
- 电子表格或手工制图纸
- 数据可信度审查表
- 修正版图表模板
- 说明短文写作框架

## 教师动作与学生动作

### 1. 同一议题的多来源数据拆解

- 学生活动: 学生选择或领取同一议题的 2-3 组数据表达，标出数据来源、样本对象、统计时间和原始结论。
- 教师动作: 教师追问“这个结论依赖什么数据没有说出来”，帮助学生把漂亮图表还原成证据链。
- 学生产出: 数据来源与结论对照表
- 关联锚点: CA-CU-013;CA-CU-015;CA-CU-057;CA-CU-085

### 2. 抽样、口径与缺失变量审查

- 学生活动: 学生用审查表判断样本是否能支持结论，找出统计口径变化、比例基数变化或缺失变量。
- 教师动作: 教师把数学中的概率统计、信息技术中的数据处理、思想政治中的公共判断放到同一张审查表里。
- 学生产出: 数据可信度审查表
- 关联锚点: CA-CU-078;CA-CU-082;CA-CU-013;CA-CU-090;CA-CU-096

### 3. 重绘图表并改写结论

- 学生活动: 学生重绘一张更诚实的图表，并把原结论改写成范围更清楚、语气更克制的说明。
- 教师动作: 教师提醒学生说明坐标轴、单位、样本、异常值和无法推出的因果关系。
- 学生产出: 修正版图表
- 关联锚点: CA-CU-078;CA-CU-082;CA-CU-015;CA-CU-086

### 4. 数据结论质询会

- 学生活动: 学生以小组为单位展示原图、审查发现和修正版图表，接受同伴围绕证据链的质询。
- 教师动作: 教师主持质询规则：所有质询必须回到数据、口径、图表表达或公共影响，不做空泛评价。
- 学生产出: 课堂辩论材料
- 关联锚点: CA-CU-057;CA-CU-058;CA-CU-085;CA-CU-090

### 5. 面向真实受众的可信说明

- 学生活动: 学生写一段面向同学或家长的可信说明，交代数据能说明什么、不能说明什么。
- 教师动作: 教师要求学生用“我现在更愿意相信/暂不相信，因为……”收束证据判断。
- 学生产出: 说明短文
- 关联锚点: CA-CU-058;CA-CU-063;CA-CU-086;CA-CU-096

## 评价量规

| 维度 | 达标表现 |
| --- | --- |
| 证据追溯 | 能说清数据来源、样本范围、时间和口径，并指出至少一个证据限制。 |
| 统计与图表判断 | 能发现样本、比例、坐标轴或变量选择中的问题，并用修正版图表回应。 |
| 结论克制 | 能区分数据支持的判断和数据无法推出的判断，避免因果偷换。 |
| 公共表达 | 能面向真实受众写出清楚、可质询、有来源意识的说明。 |

## 可直接给学生的产出提示

- 我们的判断对象是什么？
- 我们使用了哪些证据？这些证据有什么限制？
- 不同学科分别帮我们看见了什么？
- 我们最后愿意相信什么、保留什么怀疑、建议怎样行动？
